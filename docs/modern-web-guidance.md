# Modern Web Guidance for Atlasade

Use `$modern-web-guidance` for platform choices and `$atlasade-visual-design` for what the merchant should learn. Quiet Orbit supplies type, surfaces and labels. MotionSites informed the limited use of depth and illuminated connections. Every Joule informed the choice to let a visitor vary one input and explain the result. Browser guidance helps choose the least expensive accessible way to deliver that interaction. Product claims still come from the approved public release.

## Setup and provenance

The repository contains the Codex skill entrypoint. From the website root, install its separately locked CLI once with Node 22 or newer. Subsequent searches, retrievals and scans work offline. In a new Codex turn opened in this checkout, try `Use $modern-web-guidance and $atlasade-visual-design to plan a fictional drawer-count lesson. Planning only.`

```sh
npm ci --prefix .agents/skills/modern-web-guidance --ignore-scripts --no-audit --no-fund
node .agents/skills/modern-web-guidance/run.mjs search "size aware component layout"
node .agents/skills/modern-web-guidance/run.mjs retrieve size-aware-styling
node .agents/skills/modern-web-guidance/run.mjs legacy-scan src --max-files 0 --json
```

## Read-only assessment

The scan ran against a clean archive of qualified website source `b622dd29025cc9171cf9ed4f5b58aedf168fab08`. The 008B baseline adds skill and release documentation to that source. Running `legacy-scan <archive-directory> --max-files 0 --json` examined 50 files with 52 deterministic rules from 38 guides. The scanner skipped nine documentation or test files. It returned one finding, in the build-time sort below. The other recommendations come from source inspection and one controlled browser experiment.

| Priority | Evidence and decision |
| --- | --- |
| **Worth implementing** | In `public/finder/ui.js`, feature detection for `AbortSignal.timeout` would keep release revalidation working on older devices. At 390 px, Chromium 149 returned two results for “oat bar” from the local build. With only that method made unavailable, the same good manifest produced “Current release required” and hid search. Use an `AbortController` and a cleared timeout where supported. Preserve the deadline, actual manifest comparison and refusal to answer on failure. Verify current, stale and unreachable manifests with both paths. This emulates the missing API, not a specific Safari release. Record supported browser floors with the owner before dropping any fallback. |

## Joint skill qualification

Codex App Server found both enabled skills at repository scope. An explicit ephemeral, read-only invocation produced a drawer-count lesson using the actual offline search results and the `motion` and `size-aware-styling` guides. The nested planning session could not launch its own shell command, so it received those pre-run outputs together with the existing fixture and approved mobile reference. No lesson was implemented.

The proposed learner changes counted cash from $208.40 to $207.40 for the same receipt. Expected cash stays $208.40, the variance becomes −$1.00, and the fictional drawer remains open for a recount. Native controls, visible arithmetic, a stacked default and optional brief emphasis keep the comparison understandable with touch, keyboard, reduced motion or an older layout engine. A third count tests whether the learner can predict the outcome unaided. Mobile latency, bytes and learner comprehension are future acceptance measurements.

All 35 existing website checks passed. Fresh production and preview outputs each matched all 41 paths and SHA-256 hashes in their respective verified release manifests. Qualification used local artifacts. The public website did not receive a deployment.
