# Quiet Orbit

The merchant should be able to identify the record, its location, and the change before touching a control. River & Oak is the reference composition. Its paper receipt carries identity and payment. Nearby stock and finance records show the effects of that same sale. Treat the café photograph as light and place behind the records.

## Record connections

Attach each line to both the source and destination. Use a 1–1.5px static line with a visible endpoint and a short text description of both records. On activation, emphasize the source, travel along the existing route for 950ms, then emphasize the destination and settle. The café uses a shorter 240ms interaction for a single trace. Replaying a visual explanation must leave the business state intact.

Use keyboard-operable native links and buttons, a visible outline on both light and dark surfaces, and text or shape in addition to color. Keep the complete meaning available with motion disabled. Static documentation and citations must work without JavaScript. The agent guide shares the home mark and reading surfaces and stays outside the primary merchant navigation.
