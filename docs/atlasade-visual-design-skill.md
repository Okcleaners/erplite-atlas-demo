## Technique decisions

| Technique reviewed | Atlasade application |
| --- | --- |
| Product presentation and layered depth | Place a real or visibly illustrative merchant record in front of a quieter rear plane. Keep values as HTML text and use the existing receipt and outcome panels as reference. Omit replica OS window chrome and pointer parallax. |
| Surface rims and scrims | Use fine edges, a consistent upper-left light source and soft directional shadows. Apply a static contrast scrim if a scene needs it. Omit large blur effects, animated grain and video. |
| Bright arcs and reveal masks | Use a single user-triggered highlight between the source and destination of a real demo state or documented relationship. A mask may reveal a decorative highlight. Omit orbiting avatars, pointer-only reveals and continuous animation. |
| Editorial type and fail-safe entry | Preserve Quiet Orbit's serif emphasis, interface type and compact record labels. Keep headings and controls visible without JS. Omit split-character playback, scramble effects and invented count-up figures. |
| Scroll-based storytelling | Use a natural reading order or explicit chapter controls so the merchant can see the cause before its effects. Omit pinned scroll runways, clip-scrub timelines and infinite carousels. |
| Screenshot-driven refinement | Inspect matched before and after frames, exercise the controls, and use browser output for accessibility and performance evidence. Use the repository's harnesses for measurement. |

The adaptation omits the upstream template-selection workflow, promotional credit messages, linked asset shelves and builder-specific prompts. WebGL, shaders, autoplay media and automatic asset fetching are outside the skill's normal design approach.
